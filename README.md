# Fenrir Realm — Novel Updates page JSON

A Chrome and Firefox extension for staff. It turns the Novel Updates series page you already have open into the JSON the admin series form reads.

It reads the page in your own browser, where you are signed in and past the challenge. It does not log in, does not call the API, and sends nothing anywhere.

## Install (unpacked)

**Chrome / Edge**

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. **Load unpacked**, then pick this folder.
4. Pin the extension so the button stays visible.

**Firefox**

1. Open `about:debugging#/runtime/this-firefox`.
2. **Load Temporary Add-on**, then pick `manifest.json`.
3. A temporary add-on disappears when Firefox restarts; load it again.

## Use it

1. Open a series page on Novel Updates, for example `https://www.novelupdates.com/series/solo-leveling/`.
2. Click the extension button. It shows the title and how many genres, tags and which cover it found.
3. Press **Copy JSON**.
4. In the admin panel, open **Series → New**, then **Have the page JSON from the extension?**, paste, and press **Use the pasted JSON**. The form fills.

Nothing is saved until you press Save on the form.

## What it sends

One object, `schema: "fenrir.nu.series/1"`:

| Key | From the page |
|---|---|
| `source_url` | the series slug in the address bar |
| `title` | `div.seriestitlenu` |
| `alt_titles` | `#editassociated` |
| `description_html` | `#editdescription` |
| `raw_type`, `raw_language` | `#showtype a`, `#showlang a` |
| `raw_status` | the parenthesised word in `#editstatus` |
| `release_year` | `#edityear`, refused when it is in the future |
| `genre_names`, `tag_names` | `#seriesgenre a`, `#showtags a` |
| `cover_url` | `div.seriesimg img`, forced to https |
| `nu_series_id` | the `postid-<n>` class on `<body>` |

The API maps those names to Fenrir genres and tags through the alias table, so the extension never guesses a local id.
